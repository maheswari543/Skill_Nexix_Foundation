# Personal Portfolio Website (Week 1) A responsive personal portfolio website built with HTML, CSS and a little JavaScript. It introduces me, shows my education, skills and projects, and gives visitors a way to contact me. ## About me **Maheswari Guttula** B.Tech, Computer Science and Engineering Bonam Venkata Chalamayya Engineering College (2023 - 2027) ## Features - **Hero section** with my name, a short introduction and my photo - **About** section with a short summary and key numbers - **Education** shown as a timeline (B.Tech, Intermediate, 10th Class) - **Skills** section with HTML, CSS, Python, MySQL, Java and Git, each with a level bar - **Projects** section with DocSpot, Wellness Marketplace and Heart Disease Analysis - **Contact** section with email, GitHub and LinkedIn links and a contact form - **Responsive design** that works on mobile, tablet and desktop - **Dark and light theme** button that remembers the visitor's choice - **Smooth scrolling**, a mobile menu and a highlighted active navigation link ## Technologies used | Technology | Used for | |------------|----------| | HTML5 | Page structure and semantic tags | | CSS3 | Styling, Flexbox, Grid, animations, responsive layout | | JavaScript | Theme toggle, mobile menu, skill bars, contact form | | Google Fonts | Bricolage Grotesque and DM Sans fonts | ## Project structure ``` portfolio/ ├── index.html # Page content and structure ├── style.css # All styling and responsive rules ├── script.js # Small interactive features ├── profile.jpeg # My profile photo └── README.md # Project description ``` ## How to run 1. Download or clone this repository. 2. Keep `index.html`, `style.css`, `script.js` and `profile.jpeg` in the same folder. 3. Double-click `index.html` to open it in any web browser. No installation or server is needed. An internet connection is only used to load the Google Fonts. ## What I learned - Building a multi-section web page with semantic HTML - Styling with Flexbox and CSS Grid - Making a layout responsive with media queries - Using CSS variables to create a dark and light theme - Organizing a project into separate HTML, CSS and JavaScript files - Using Git and GitHub to store my work ## Contact - Email: maheswariguttula112@gmail.com - GitHub: https://github.com/maheswari543/Skill_Nexix_Foundation - LinkedIn: https://www.linkedin.com/in/maheswari-guttula-757a3a365/ ## License This project is for learning purposes. © 2026 Maheswari Guttula.
