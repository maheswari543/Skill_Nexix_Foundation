# Personal Portfolio Website (Week 1) A responsive portfolio introducing **Maheswari Guttula**, a B.Tech Computer Science and Engineering student at Bonam Venkata Chalamayya Engineering College, graduating in 2027. The site presents her skills, projects, education, and contact links. ## Features - Hero introduction with profile photo and links to Projects and Contact - About section with career goal, strengths, and interests - Skills cards for HTML, CSS, basic JavaScript, Python basics, MySQL basics, and Git - Education details, including an 8.54 CGPA - Four project summaries: DocSpot, Wellness Marketplace, Smart Road Safety Analytics, and Weather App - Contact section with email, GitHub, LinkedIn, and an email-compose form - Responsive layouts, mobile navigation, smooth scrolling, and a dark/light theme toggle - Accessible labels, visible keyboard focus, and subtle motion effects ## Technologies | Technology | Use | |------------|-----| | HTML5 | Semantic page structure | | CSS3 | Responsive layouts, themes, cards, and animations | | JavaScript | Mobile navigation, theme control, skill indicators, and contact form | | Google Fonts | Manrope and DM Sans typography | ## Project structure ```text Week_01/ ├── index.html # Portfolio content ├── style.css # Shared styles and responsive rules ├── script.js # Theme, navigation, and contact interactions ├── profile.jpeg # Profile photo └── Readme.html # Project notes (Markdown text) ``` ## Run locally Open `index.html` in a browser, or use Visual Studio Code Live Server. The portfolio uses no build step or package installation. An internet connection is needed for Google Fonts. ## What I learned - Building a multi-section web page with semantic HTML - Styling with Flexbox and CSS Grid - Making a layout responsive with media queries - Using CSS variables to create a dark and light theme - Organizing a project into separate HTML, CSS, and JavaScript files - Using Git and GitHub to store my work ## Contact - Email: maheswariguttula112@gmail.com - GitHub: https://github.com/maheswari543/Skill_Nexix_Foundation - LinkedIn: https://www.linkedin.com/in/maheswari-guttula-757a3a365/ ## License This project is for learning purposes. © 2026 Maheswari Guttula.
