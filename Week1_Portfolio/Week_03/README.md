# Weather App

A responsive weather lookup project by **Maheswari Guttula**. Enter a city to view its current temperature, condition, humidity, feels-like temperature, and wind speed.

## Features

- City search using the OpenWeather current weather endpoint.
- Form submission by button or Enter key.
- Loading, empty-city, missing-API-key, invalid-key, city-not-found, and network error feedback.
- Weather condition icon and responsive details layout.
- Shared dark/light theme preference and responsive navigation to the Week 2 projects.
- Accessible form labels, status messages, visible keyboard focus, and reduced-motion support.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- OpenWeather Current Weather API

## API key

An OpenWeather API key is required to fetch live weather. Use the expandable API-key field on the page to enter your key. It is held only in the open page and is not written to local storage or source code. The browser sends the key to OpenWeather as part of the weather request. Do not commit or share your API key.

## Run locally

Open `index.html` using Visual Studio Code Live Server, or open the file directly in a modern browser. No build step or package installation is needed. The page must be online to retrieve weather data from OpenWeather and load Google Fonts.
